Equipo sugerido · 12 personas

La asignación se presenta por función, no por nombre. Cuando definan los responsables reales, se reemplaza cada rol por la persona asignada.

1. Líder del proyecto

Dirige decisiones, lidera la relación con LEL, prioriza riesgos y presenta avances del prototipo.

2. Co-líder / enlace

Coordina tareas, hace seguimiento diario y reemplaza al líder cuando se requiere.

3. Analista del proceso

Mapea etapas, responsables, entradas y salidas para mantener la matriz de requisitos.

4. Diseñador pedagógico

Convierte los módulos en sesiones, actividades, evidencias y rúbricas de evaluación.

5. Investigación de usuarios

Valida necesidades con LEL, mentores y jóvenes, y documenta hallazgos relevantes.

6. UX / flujo de usuario

Diseña formularios, navegabilidad, estados y mensajes para lograr una experiencia clara.

7. UI / identidad visual

Define colores, tipografía y componentes para una presentación coherente con LEL.

8. Prototipado / front-end

Construye las vistas del prototipo y conecta la experiencia con datos de prueba.

9. Datos e indicadores

Establece fórmulas, tableros y reportes de inscripción, retención y graduación.

10. Contenido y comunicaciones

Redacta la convocatoria, mensajes y guías para redes y difusión del programa.

11. QA y documentación

Prueba flujos, detecta errores y prepara un manual breve de uso del proceso.

12. Relatoría y pitch

Organiza evidencias, prepara la demo y entrega una presentación clara para cierre del piloto.
